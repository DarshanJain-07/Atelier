# Welcome to ATELIER

**ATELIER** (A Hybrid Neuro-Symbolic Multi-Agent Framework for Predicting Public Sentiment Dynamics, Emotional Contagion, and Backlash in Digital Ecosystems) is an advanced multi-agent social simulation platform.

The framework utilizes a **hybrid architecture**:
1.  **Perception Layer (Neuro-Symbolic):** Uses an LLM to translate unstructured text into a structured 12-dimensional "World Tensor".
2.  **Simulation Layer (Deterministic PyTorch):** Feeds the World Tensor into a high-performance simulation modeling Big Five personality traits, memory, and cognitive biases.
